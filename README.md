## 🔧 Features

- 💬 Chat with AI using natural language
- 🧠 Powered by OpenAI or custom logic
- 🌐 Frontend built with HTML, CSS, JS
- 📁 Supports Excel input/output
- 🚀 Lightweight, easy to deploy

---

## 🛠️ Installation

### ✅ Prerequisites

- Python 3.8+
- pip
- Modern browser (Chrome, Firefox)
---

### ⚙️ Steps to Install

1. **Clone the repo**

```bash
git clone https://github.com/Saikoushik-18/College-Ai-Chatbot.git
```
```bash
cd College-Ai-Chatbot
```
```bash
pip install -r requirements.txt
```
```bash
python app.py
```
